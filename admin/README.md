# PHP / MySQL Admin Paneli

## Kurulum

1. XAMPP içinden Apache ve MySQL servislerini başlatın.
2. phpMyAdmin'i açın: `http://localhost/phpmyadmin`
3. **İçe Aktar** bölümünden `schema.sql` dosyasını çalıştırın.
4. Gerekirse `db.php` içindeki veritabanı kullanıcı adı ve şifresini değiştirin.
5. Paneli açın: `http://localhost/site/admin/login.php`

## Örnek hesaplar

- Yönetici: `admin@site.com` / `Admin123!`
- Kullanıcı: `kullanici@site.com` / `User123!`

Canlı ortamda örnek şifreleri mutlaka değiştirin ve HTTPS kullanın.
